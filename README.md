## Run it locally

> **You'll need** [Node.js](https://nodejs.org) **20.19+** or **22.12+**.

```bash
# 1. Install dependencies
npm install

# 2. Start the dev server with hot reload
npm run dev
```

Then open **http://localhost:5173**
